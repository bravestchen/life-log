# 个人健康学习记录应用 - Demo

基于产品需求文档创建的演示应用，用于记录个人的健康和学习数据。

## 功能特性

### 核心功能
- **学习记录**：记录书籍阅读、在线课程、技能练习等学习活动
- **健康记录**：记录运动数据（跑步、瑜伽等）和身体数据（体重、睡眠、步数）
- **时间轴视图**：按时间倒序展示所有记录，支持筛选
- **数据统计**：可视化展示学习时长、运动时长、类型分布等数据
- **本地存储**：数据存储在浏览器本地，无需服务器

### 用户界面
- **响应式设计**：适配桌面端和移动端
- **暗黑模式**：支持浅色/深色主题切换
- **PWA支持**：可添加到手机主屏幕，支持离线访问
- **直观导航**：侧边栏导航，快速切换不同视图

### 数据管理
- **数据导出**：导出JSON格式的完整数据备份
- **数据导入**：从备份文件恢复数据
- **示例数据**：首次使用时自动生成示例记录

## 技术栈

- **前端**：纯HTML/CSS/JavaScript，无框架依赖
- **存储**：localStorage + IndexedDB模式
- **图表**：Chart.js 数据可视化
- **样式**：CSS变量实现主题切换，Flexbox/Grid布局
- **图标**：Font Awesome 图标库

## 运行方法

1. **直接打开**：在浏览器中打开 `index.html` 文件
2. **本地服务器**（推荐）：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 或使用Node.js的http-server
   npx http-server
   ```
   然后访问 `http://localhost:8000`

3. **移动设备**：通过本地网络IP地址访问（如 `http://192.168.x.x:8000`）

## 使用说明

### 首次使用
应用首次打开时会自动生成5条示例记录，方便您了解功能。

### 添加记录
1. 点击右上角「添加记录」按钮或首页的快速记录按钮
2. 选择记录类型（学习、运动、身体数据）
3. 填写相关信息
4. 点击「保存记录」

### 查看记录
- **今日概览**：查看连续记录天数、今日学习/运动时长
- **时间轴**：按时间顺序浏览所有记录，支持筛选
- **学习记录**：仅查看学习相关的记录
- **健康记录**：查看运动和身体数据记录

### 数据统计
- **本周数据**：柱状图展示本周学习vs运动时长
- **类型分布**：饼图展示学习类型和运动类型的分布

### 数据管理
- **导出数据**：在设置页面导出JSON备份文件
- **导入数据**：从之前导出的备份文件恢复数据
- **清除数据**：清空所有记录（谨慎操作）

### 主题切换
点击右上角的月亮/太阳图标切换浅色/深色主题。
